# Запуск на bothost.ru

В этой папке всё вместе: Telegram-бот, сайт и кабинет. На хостинге это один бот:

- сайт: `https://ваш-домен/`
- кабинет для мастеров: `https://ваш-домен/cabinet/`

## 1. Токен бота

Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен. Не кладите его в файлы этой папки.

## 2. Тариф

Нужен тариф **Базовый** (99 ₽/мес) или выше. На бесплатном данные стираются при перезапуске, то есть пропадут все записи.

## 3. Загрузите код в закрытый репозиторий GitHub

Создайте на GitHub **приватный** репозиторий и выполните в этой папке:

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "Первая версия"
```

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
```

```bash
git push -u origin main
```

Доступ Bothost к приватному репозиторию настраивается по их статье: https://bothost.ru/docs/git-repository-access

На платном тарифе можно без Git: включите «Загрузка бота из архива» в профиле и загрузите zip-архив этой папки. По их документации это пока работает на одной тестовой ноде, поэтому выбрать локацию там может не получиться: проверьте, что сервер в России.

## 4. Заполните форму

| Поле | Что указать |
|---|---|
| Название бота | Loona |
| Платформа | Telegram |
| Язык разработки | Node.js |
| Bot Token | токен от @BotFather |
| Локация | **Россия (Москва)**: данные клиентов из России нужно хранить в России |
| Переменные окружения | «Загрузить из файла .env», файл `bothost.env` из этой папки |
| Git URL, ветка | ваш репозиторий, `main` |

В «Дополнительных настройках»:

| Настройка | Значение |
|---|---|
| Использовать домен | включить |
| Порт | `3000` |
| Использовать собственный Dockerfile | **включить**: нужен Node 24 |
| Главный файл | `server.mjs` |

Запустите деплой.

## 5. После первого запуска

1. В логах должны появиться строки `cabinet:` и `bot: @имя_бота`.
2. Если вместо этого написано `Telegram is not answering`, бот не достучался до Telegram с этого сервера. Напишите в поддержку Bothost (@Bothostru), есть ли доступ к Telegram из московской локации.
3. Узнайте домен бота и добавьте переменную `PUBLIC_URL=https://ваш-домен`, затем сделайте новый деплой. Без неё бот не покажет ссылку на политику данных.
4. Откройте в файловом менеджере панели `data/first-logins.txt`: там логины и пароли. Войдите в кабинет и **удалите этот файл**.
5. Откройте `https://ваш-домен/health`: должно быть написано `ok`.

## 6. Перед тем как показывать клиентам

- [ ] В кабинете заменить примерные услуги, цены и длительность на настоящие.
- [ ] Заменить примерных мастеров на настоящих: сейчас их имена видны на сайте. Каждому настроить график и подключить Telegram в «Настройках».
- [ ] Заменить стоковые фото настоящими и убрать подпись о них в подвале сайта. Это делается в основном проекте (`sites/loona`), затем папка собирается заново.
- [ ] Заполнить в `site/privacy.html` всё в квадратных скобках: оператор, контакты, срок хранения. Показать текст юристу.
- [ ] Сделать пробную запись через бота и через сайт, отменить её, проверить, что всё приходит мастеру.

## Обновление и копии

- Новая версия: `git add .`, `git commit`, `git push`, затем деплой. База в `data/` при этом не трогается.
- Сервер раз в сутки кладёт копию базы в `data/backups` и хранит 14 штук. Время от времени скачивайте их через файловый менеджер.
